# Task 2 — Fuzzy Logic Controller + Evolutionary Optimisation

Fully separate from Task 1's Python code (`src/`, `app/`) — this is a
self-contained MATLAB deliverable for **ST7085CEM Task 2** (Fuzzy Logic
Optimized Controller for an Intelligent Assistive Care Environment).

**Scenario chosen**: a fuzzy PD thermostat controlling a combined
heater/cooler actuator for one room in the assistive-care flat, using
temperature error and its rate of change as inputs — a classic, easy to
justify, easy to visualize FLC design.

There is no MATLAB in this environment, so the MATLAB code itself has not
been executed here. The *algorithms*, however, have been verified: the GA,
the PSO, the CEC benchmark functions, the chromosome decoder and the
Mamdani inference engine were all re-implemented in Python and run, which
is how the membership-function coverage bug in `apply_chromosome.m` was
found and fixed (see below). You still need to run the MATLAB yourself
(Fuzzy Logic Toolbox required; Global Optimization Toolbox is *not*, since
the GA/PSO are hand-written) and report the numbers MATLAB produces.

**Bug found and fixed during that verification:** the original
`apply_chromosome.m` shrank every membership function toward the domain
midpoint when a chromosome's scale gene was below 1, leaving the ends of
each universe of discourse uncovered. At `scale = 0.6` — well inside the
GA's own search bounds — 196 of the 300 reference inputs fired *no rule at
all*, so the fitness function was silently meaningless over a large part
of the search space. The decoder now pins the outer shoulders of the first
and last membership function to the domain edges, which guarantees full
coverage for every chromosome the GA can generate.

## Structure

```
part1_flc/
  build_flc.m           Constructs the Mamdani FIS (2 inputs, 1 output, 15 rules)
  analyze_flc.m         MF plots, control surface, per-rule firing strengths,
                        and a closed-loop step response vs a linear PD controller
  thermostat_flc.fis    (generated by build_flc.m)

part2_ga_tuning/
  generate_reference_dataset.m   Synthetic (input, target-output) dataset for tuning
  apply_chromosome.m             Decodes a 6-gene chromosome into MF parameters
  ga_tune_flc.m                  Runs the GA, saves before/after comparison plots

part3_optimizer_comparison/
  cec_functions.m        Shifted Sphere (F1) and Shifted Rastrigin (F9) benchmarks
  run_comparison.m       Runs GA vs PSO, D=2 and D=10, 15 runs each, saves results/plots

shared/
  custom_ga.m            Real-coded GA (tournament selection, BLX crossover, Gaussian mutation)
  custom_pso.m           PSO (same velocity/position update style as Task 1's Python PSO)
  simulate_room.m        First-order room thermal model + closed-loop simulator,
                         used by Part 1's scenario analysis and Part 2's validation
```

## How to run (in order)

```matlab
cd part1_flc
build_flc        % builds & saves thermostat_flc.fis
analyze_flc       % saves membership_functions.png, control_surface.png, scenario_results.csv

cd ../part2_ga_tuning
generate_reference_dataset
ga_tune_flc        % saves thermostat_flc_tuned.fis, ga_convergence.png, before_after_mfs.png

cd ../part3_optimizer_comparison
run_comparison      % saves optimizer_comparison_results.csv + convergence_*.png (takes a few minutes)
```
